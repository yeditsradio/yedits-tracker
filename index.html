HOW THIS WORKS
Structure
Every song sits inside its era. Open a song for two tabs.

Ranked — edits competing to be the best version. Ties are allowed: two edits can both be #1.
Special — edits doing their own thing. Graded A–D, not ranked.
Edit types
Overhaul
Full creative reimagining, driven by the editor's own vision but still rooted in the source.
e.g. Luwi & Lilac — Over
Renovation
Sweeping changes expanding the era's original vision, source still recognizable.
e.g. underdawg — On Sight
Vanilla-Style
Faithful above all else — QoL edits and refinements, little outside direction.
e.g. SimpleJosh — Nobody To Love
Extension
Expands runtime using official or remix material, little custom production.
e.g. any Radical Redux edit
Remix
Reimagines the source through a different existing style rather than the editor's own.
e.g. club remixes, JPEG edits
Scoring
Ranked — #1 = 3   #2 = 2   #3 = 1   #4 = 0.5
Past #4 becomes an HM, also 0.5, unlimited per song
× √(filled slots ÷ 4), capped at 1

Special — A = 3   B = 2   C = 1   D = 0.5
Grades aren't a ranking — several edits can share one.

Both — × 1.25 if highlighted ★  ·  ÷ √(credited editors)

Comps board uses the same maths on comps only. WIP and cancelled comps score nothing.
Note
Type colour is descriptive, not a ranking. All data comes from the linked Google Sheet — edit the sheet and the site follows.
