HOW THIS WORKS
Structure
Every song sits inside its era. Open a song to see two tabs, each holding four slots.

Ranked — edits competing to be the best version of the song. Ranked 1–4.
Special — edits doing their own thing rather than chasing "best". Unranked.
Edit Types
Overhaul
Full creative reimagining of the era, driven entirely by the editor's own vision but still rooted in the source.
e.g. Luwi & Lilac — Over
Renovation
Sweeping changes that expand on the era's original vision, with the editor's own style present but the source still recognizable.
e.g. underdawg — On Sight
Vanilla-Style
Faithful to the source above all else, sticking to QoL edits and refinements with little outside creative direction.
e.g. SimpleJosh — Nobody To Love
Extension
Focused on expanding the runtime using official or remix material, with little to no custom production.
e.g. any Radical Redux edit
Remix
Reimagines the source through an entirely different existing style rather than the editor's own.
e.g. club remixes, JPEG edits
Leaderboard Scoring
Ranked tab — by rank
#1 = 3   #2 = 2   #3 = 1   #4 = 0.5

Special tab — by grade

Note
Type colour is descriptive, not a ranking. An Overhaul in the Ranked tab and an Overhaul in the Special tab carry the same colour — the tab decides whether it is ranked.
