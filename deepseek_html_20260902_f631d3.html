HOW THIS WORKS
Structure
Every song sits inside its era. Open a song to see two tabs, each holding edits.

Ranked — edits competing to be the best version. Each edit has a rank (1–4 or HM).
Special — edits doing their own thing, graded A–D.
Edit Types
Overhaul
Full creative reimagining rooted in the source.
Renovation
Sweeping changes that expand on the original vision.
Vanilla-Style
Faithful to the source with QoL refinements.
Extension
Expands runtime using official or remix material.
Remix
Reimagines the source through a different existing style.
